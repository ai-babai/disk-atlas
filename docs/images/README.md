# Interface screenshots

Refreshed on November 10, 2026 from the **0.15.2 (34)** interface,
source revision `f3728326d9a448c3e571705f6fc82f1985da9c40`.

The images show the app's native views with fabricated metadata rooted at
`/Volumes/Studio`. Folder names, file paths, capacities, sizes, dates and durations
are illustrative, not measurements of a user's disk or performance benchmarks.
No real scan history, personal paths or file contents are included.

| Images | What they show |
| --- | --- |
| `workspace-dark.png`, `workspace-light-ru.png` | Map selection, expanded folder tree and inspector |
| `start-en.png`, `start-ru.png` | Disk capacity, folder selection and recent saved snapshots |
| `duplicates-en.png`, `duplicates-ru.png` | Expanded copies, explicit checkboxes and selected byte total |
| `history-en.png`, `history-ru.png` | Snapshot and duplicate-report storage sizes |
| `trash-review-en.png`, `trash-review-ru.png` | Full-path review and the remaining copy |

English images use the dark theme; Russian images use the light theme.
Screenshots capture only the relevant app content, excluding system title bars
and capture indicators. No cleanup action was executed to produce them.
The demonstration data and temporary rendering app are not distributed with
Disk Atlas and are not part of the repository.
