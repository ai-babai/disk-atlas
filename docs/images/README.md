# Interface screenshots

Refreshed on November 12, 2026 from the **0.15.5 (37)** interface,
source revision `0e36f4ad884a39ab1df9b669204627f82e9b6002`.

The images show the app's native views with fabricated metadata rooted at
`/Volumes/Studio`. Folder names, file paths, capacities, sizes, dates and durations
are illustrative, not measurements of a user's disk or performance benchmarks.
No real scan history, personal paths or file contents are included.

English images use the dark theme; Russian images use the light theme.
Screenshots capture only the relevant app content, excluding system title bars
and capture indicators. Only the outer title-bar strip is cropped; interface
content and colors are not retouched. No cleanup action was executed, no feedback
was sent and automatic diagnostics stayed off. The feedback text is a fabricated
example, not an actual user report.
The demonstration data and temporary rendering app are not distributed with
Disk Atlas and are not part of the repository.
